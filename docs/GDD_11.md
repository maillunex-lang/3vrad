# GDD-11 - Игровое ядро Match-3

Статус: APPROVED. Решения утверждены владельцем. Детали GDD-12 ещё не утверждены.

- MATCHCORE-001 C: классический обмен соседних фишек, создающий совпадение, плюс разрешённый обмен двух соседних усилителей без обычного совпадения.
- COMBO-001 B: четыре специальных усилителя: ракета (четыре в линию), кокосовая бомба (Т/Г), радужная жемчужина (пять в линию), пропеллер (квадрат 2×2).
- COMBO-002 B: мощные, но сбалансированные взаимодействия усилителей, не гарантируют автоматическую победу.
- CASCADE-001 C: зрелищные последовательные каскады с растущими множителями очков; падение обычное вертикальное, если иное не утверждено отдельно.
- BLOCK-001 B: новые механики препятствий вводятся приблизительно каждые 10–15 уровней.
- HELP-001 C: подсветка возможных ходов, перемешивание при тупике и необязательная помощь после нескольких поражений; без рекламы.

Открыто для GDD-12: радиусы взрывов, выбор цели пропеллера, цепные взаимодействия, слои прочности, правила повреждения препятствий, награды за каскады, конкретная помощь после поражений.

Важное ограничение: не считать предложения из неутверждённого GDD-12 каноном. Перед реализацией неоднозначных правил запросить утверждение или документировать временное обратимое решение.
