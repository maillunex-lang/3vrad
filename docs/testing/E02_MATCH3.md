# E02 — ручная приёмка ядра Match-3

## Автоматические проверки
```bash
cd apps/client && npm test && npm run typecheck && npm run build
```
Ожидание: тесты `matches`, `engine`, `viewport` зелёные; 10 verify-уровней проходят autoplay без исключений; v01/v02 выигрываются.

| # | Шаг | Ожидание |
|---|-----|----------|
| 1 | Открыть клиент | Поле Match-3, HUD ходы/очки/цели |
| 2 | Тап двух соседних фишек с матчем | Обмен, очистка, каскад, анимация вспышек |
| 3 | Тап без матча | Откат, ход не списан |
| 4 | Пройти v01 (Подсказка → ходы) | Цель collect mango выполнена / Победа |
| 5 | Кнопка «Сл. ур.» | Переключение v01…v10, размеры 6×6–9×9 |
| 6 | Уровень с ящиком/льдом | Слои видны; урон от соседнего матча |
| 7 | Собрать 4 в линию | Появляется ракета |
| 8 | Подсказка | Подсветка возможных ходов |
| 9 | Исчерпать ходы 3 раза | Предложение стартового усилителя |
| 10 | Нет зависания при длинном каскаде | Каскад обрывается/shuffle по ADR-002 |
